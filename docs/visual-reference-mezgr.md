# 洗練モードの視覚言語リファレンス（Mezgr 参照）

2026-07-29 作成。https://mezgr.com のマーケティングページとデモ動画から実測・観察したもの。
**模倣のためではなく、方向性を言語化して案出しの土台にするための記録。**
ロゴ・固有の写真素材・書体そのものは使わない（Louize / innovatorGrotesk は商用ライセンス書体）。

## 実測したブランド値

| 項目 | 値 |
|---|---|
| 地色 | `rgb(6, 7, 10)` — 純黒ではなく、わずかに青紫寄りの黒 |
| 文字色 | `rgb(246, 245, 232)` — 純白ではなく **暖かいオフホワイト（骨色）** |
| 見出し書体 | Louize（コントラストの高いセリフ、weight 500） |
| 本文書体 | innovatorGrotesk（ニュートラルなグロテスク） |

**署名的な選択は2つ**: ①純白を使わず骨色にしていること、②セリフ見出し × グロテスク本文の組み合わせ。
この2つだけで「car enthusiast 向けの落ち着いた高級感」が出ている。

## アプリ画面から観察したパターン

デモ動画のフレーム（4s / 9s / 14s / 19s / 24s）より。

### 1. 面の作り
- 地は near-black。カードは**わずかに明るいチャコール**＋極細のボーダーで浮かせる
- 角丸は 16〜20px 程度。ピル型ボタンは完全な丸
- 影はほぼ使わず、明度差とボーダーで階層を作る

### 2. Console（2列メトリクスタイル）
車両詳細画面の中核。2列グリッドに数値タイルを並べる。
- タイル構成: 小さいアイコン＋ラベル（上） → **大きな数値**（下） → 補足キャプション
- 各タイル右上に開閉シェブロン
- **主要タイルだけ深い緑にティント**し、他はニュートラルなチャコール。
  色は「重要度」を表しており、装飾ではない
- 例: `Valuation $43,750 / Updated 1 week ago`（緑）、`Market $43,250 / 14 comps`（無彩色）

### 3. 統計行
`Since / Mezgr Miles / Feet Climbed` を3列に並べ、**縦のヘアラインで区切る**。
ラベルは小さく淡く、値は大きく明るい。

### 4. リスト
- 行間はヘアラインのみ（塗りの分割線を使わない）
- 分類は**小さな緑のピルバッジ**（`Mods`）
- 行末にシェブロン

### 5. アクション
- 主要CTAは**彩度の高いエレクトリックブルーのピル**。画面内で1つだけ
- 副次アクションは円形のアイコンボタン（チャコール地）

### 6. テレメトリ表現
地図上の走行ラインを**速度グラデーション**（青→緑→黄→赤）で描く。
その上にデータカードを重ね、`1 mi` のような**巨大な数値**＋2×3の統計グリッドを載せる。

### 7. ナビゲーション
下部タブバー（Community / Drives / Garage / Profile）。
アクティブ項目は**ピル状のハイライト**。アイコン＋ラベルの縦積み。

### 8. 車両の見せ方
車両画像を白〜グレーのグラデーション上に置き、**車そのものを主役**にする。
その下に情報を積む。

## VELOCITY LOGGER に持ち込めるもの

| 持ち込む | 適用先 |
|---|---|
| near-black 地 ＋ チャコールカード | 全画面の基調 |
| Console 型の2列メトリクスタイル | ダッシュボード、セットアップ詳細 |
| 主要タイルだけティント（意味を持つ色） | 目標空気圧の範囲内/外、ベスト更新 |
| ヘアライン区切りの統計行 | セッション情報バー、スペックカード |
| 巨大な数値 ＋ 小さいラベル | 空気圧入力、ラップタイム表示 |
| 速度グラデーションのトレース | テレメトリ解析（既存の描画に適用可能） |
| 暖かいオフホワイト（純白を避ける） | 全体の文字色 |
| 彩度の高いCTAを画面に1つだけ | 保存ボタン |

## 持ち込まないもの

- 商用ライセンス書体（Louize / innovatorGrotesk）。システムフォントか OFL 書体で代替する
- 写真ベースのヒーロー。VELOCITY LOGGER の主役は写真ではなく計測値
- ロゴマーク・配色そのもののコピー

## 制約（洗練モードでも外さない）

ユーザー判断により、洗練モードは**全画面に適用しつつピット要件を維持**する。

- タップターゲット **60px 以上**
- コントラスト **7:1 以上**
- 主要操作は親指到達域（390×844 で y≥281）
- 圏外での保存完走

**near-black 地 ＋ 骨色の文字は、この制約と相性が良い**（実測で18:1前後が出る）。
危ないのは「小さく淡いラベル」と「ティントしたカード上の文字」で、そこだけ検証が要る。
検証は `src/lib/pitTheme.test.ts` と `node audit/measure.mjs` がそのまま使える。
